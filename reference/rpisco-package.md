# rpisco: Access and Process PISCO High-Resolution Climate Grids for Peru

The `rpisco` package provides programmatic access, automated caching,
spatial subsetting, temporal analysis, and hydrological validation
metrics for the Peruvian Interpolated data of SENAMHI's Climatological
and hydrological Observations (PISCO).

## Details

Supports the PISCO datasets included in the package catalog:

- **Precipitation (PISCOp)**: PISCOp v3.0 (1981-2025; daily, monthly,
  and climatological normal).

- **Temperature (PISCOt)**: PISCOt v1.2 (maximum and minimum daily data
  and climatological normals).

- **Evapotranspiration (PISCOeo_pm)**: PISCOeo_pm monthly climatological
  reference evapotranspiration.

- **Rainfall Erosivity (PISCO_reed)**: PISCO_reed v1.0 (1981-2016;
  R-factor climatology and annual erosivity series).

- **Streamflow (PISCO_HyM)**: Monthly gridded and vector streamflow
  (1981-2016) based on hydrological modeling (GR2M and ARNOVIC) with
  sub-basin polygons and river reach networks.

Datasets are hosted on Figshare and HydroShare by SENAMHI and
collaborating researchers. See
[`pisco_catalog`](https://PaulESantos.github.io/rpisco/reference/pisco_catalog.md)
and
[`pisco_citation`](https://PaulESantos.github.io/rpisco/reference/pisco_citation.md)
for links, dataset keys, and scientific citations.
